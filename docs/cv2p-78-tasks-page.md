# Tasks page (CV2P-78)

The sidebar Tasks page at `/tasks` collates existing application tasks and new standalone or lead-linked tasks in `application_activities`. Counsellors see their own assigned tasks. Managers see their own tasks and staff assigned to their accessible offices. Regional managers also include offices in their managed regions. Admin and Super Admin see all tasks, including unassigned legacy records. Visibility depends on the task assignee, independently of the related application's case handlers or the task creator. Related references are text so the page does not offer case links that exceed existing record permissions.

The six columns are Task Description, Complete by date, Relates to, Assignee, Task created by and Status. Description and related Lead/application IDs support literal substring searches. Application IDs also accept the five-digit numeric list format. Assignee, creator and status filters allow multiple selections and combine with the searches. Complete by date sorts in either direction with undated legacy tasks last. Pagination uses the client list's 10/20/50 sizes and retains filters.

Add new task opens a dialog with required description, complete-by date (today or later), active unrestricted assignee and one of To Do, In Progress, Pending External or Done. The creator is set by the server. Optional Lead/application references require existing record access. Failed submissions restore valid drafts and reopen the dialog. Cancel and Escape dismiss the dialog without writing.

CSV downloads include every permitted matching row in the displayed order, independent of the current page, with the filename `Tasks -YYYYMMDDhhmmss.csv`, UTF-8 BOM and formula protection. Existing Pending and In progress statuses display/filter as To Do and In Progress. Organisation forms offer the four current statuses while accepting legacy submissions. Restricted assignees are rejected by both the page and organisation task routes.

Run `php artisan migrate` and `npm run build` for deployment. Migration `2026_11_13_000001_extend_tasks_for_global_list` allows standalone tasks, adds optional Lead and creator relationships, and assigns old unassigned application tasks to the application's primary counsellor. Unknown historical creators remain unknown. Rollback retains task rows and nullable application IDs.
